# Сайт-портфолио Чингиза

## Что внутри
- `index.html` — вся страница
- `assets/` — видео, картинки, шрифты

## Как выложить
Любой хостинг статики, ничего настраивать не надо:
- **Netlify** — netlify.com/drop, перетащить папку в окно браузера. Ссылка появится сразу.
- **Vercel**, **Cloudflare Pages**, **GitHub Pages** — так же, залить папку целиком.
- Свой хостинг — закинуть содержимое папки в корень домена.

Главное: заливать папку целиком, вместе с `assets`. Отдельный `index.html` работать не будет.

## Что менять руками
Всё в `index.html`, обычным текстовым редактором.

- **Телефон и Telegram** — искать `t.me/c.hingiz` и `+79625382518`
- **Цены** — блок `<section>` с заголовком «Цены»
- **Ссылки на работы** — в блоке «Работы», атрибут `href` у каждой карточки
- **Цифры** — блок `class="nums"`

## Как заменить картинку
Положить новую в `assets/img/` под тем же именем — страница подхватит.

Имена файлов:
- `w_podcast`, `w_catering`, `w_concert`, `w_walk`, `w_love` — обложки работ
- `d_sde`, `d_brands`, `d_people`, `d_events`, `d_pranks` — кадры, которые всплывают при наведении на SDE / Бренды / Люди / События / Пранки
- `me` — портрет, `story` — фото под столом, `revs` — коллаж отзывов
- `stats1`, `stats2` — скриншоты просмотров

## Видео на первом экране
`assets/hero_h.webm` + `hero_h.mp4` — горизонталь для компьютера
`assets/hero_v.webm` + `hero_v.mp4` — вертикаль для телефона

Меняешь шоурил — пересобери оба формата, иначе часть браузеров не покажет видео.
